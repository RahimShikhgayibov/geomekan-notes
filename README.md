# geomekan-notes

Daily learning notes on GIS and geospatial data. One topic per day, one file per topic.

Notes are written in Azerbaijani. Every note follows the same shape:

1. **Nə** — what it is
2. **Niyə** — why it exists / why it matters
3. **Sadə nümunə** — a small, made-up example
4. **Tipik səhv** — a common mistake
5. **Xülasə** — a one-sentence summary
